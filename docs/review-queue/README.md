# Work-item plans

This directory retains implementation plans tied to specific changes and continuity
records. The old Markdown daily queue and `pending.md` tracking system were retired;
duplicate daily records were removed on September 29, 2026.

`PLAN_*.md` files preserve objectives, reasoning, proposed files and verification.
A plan's presence or age does not establish whether its work is complete. Check the
current source and the relevant live continuity records before acting on it.

Use the existing [MCP continuity tools](../architecture/mcp-server.md) for current
work: `todo_list`, relevant `memory_get` / `memory_search`, `lessons_list`, and
`app_rules_list`. Follow [AGENTS.md](../../AGENTS.md) and [CLAUDE.md](../../CLAUDE.md)
for startup and attribution. Do not rebuild a parallel Markdown task queue.

Historical daily reviews and the retained copies of the old fix plan/workstream are
in [reviewed-queue](../reviewed-queue/README.md). Deletion reasons and recovery pointers
are in [the September 29 cleanup record](../architecture/removals/2026-09-29-documentation-cleanup.md).
